# Codex PDF to EPUB

I'm using Codex to convert PDFs to EPUBs, and getting it to maintain an instruction manual containing all generalisable corrections I find, such as incorrect punctuation marks, line breaks, italicisation, bolding, and so on. This also works for books and essays that have been made available online in HTML, such as *[The Story of Zoya and Shura](https://gammacloud.org/features/zoya/story-zoya-shura/)*, in which case you can just feed Codex a URL. You should always try to feed Codex the cleanest, best-quality PDFs you have. Wherever possible, you should see if there already is a good EPUB option available: many academic journals permit you to download articles in EPUB format. Tables, graphs, diagrams, images, and mathematical equations can all be converted neatly, but only if they are sequenced in a relatively linear, clear-cut fashion. Certain books that are heavily dependent on formatting and imagery, such as textbooks or books on fashion, may not convert well to EPUBs no matter what. I like to use the Sol variant of GPT on the Medium mode as a good balance between cost and efficacy.
